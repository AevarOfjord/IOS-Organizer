# LinkedIn launch draft

I built iOS Organizer to turn a messy iPhone Home Screen into a conversation with a coding agent.

Open the project in Codex, Claude Code, or Gemini CLI, connect your iPhone to your Mac, and describe what you want:

“Keep my main page as it is. Group the rest by function and sort the folders alphabetically.”

The workflow lists your apps first, asks what should change and what must stay in place, then creates an image preview and a full folder list. You review it before anything is applied. The CLI backs up the layout and verifies the result after writing it.

Standard app and folder organization needs no Developer Mode or jailbreak.

This is an early open-source release. USB organization is implemented; exact spacing and new widgets have design previews and a conditional Mirroring/manual workflow, with automatic completion still to be verified.

I’m looking for feedback on the onboarding, compatibility, and how clearly the agent guides someone using a coding agent for the first time.
